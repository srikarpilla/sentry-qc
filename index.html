Pipeline

From camera frame to pass/fail decision

Every inspection runs through the same four stages, whether it's a bottle, a circuit board, or a length of fabric.

01

Capture

A line-mounted camera photographs each unit as it passes the inspection point.

02

Preprocess

The image is resized to 288×288. Raw pixel values (0–255) are passed directly — EfficientNet rescales internally.

03

CNN inference

A fine-tuned EfficientNetB0 backbone extracts visual features. Softmax outputs [P(defective), P(good)].

04

Route

If P(good) ≥ 0.58 → PASS. Within ±0.10 of threshold → UNCERTAIN (human review). Otherwise → FAIL.

Under the hood

Model architecture

Transfer learning on EfficientNetB0, fine-tuned for binary defect detection on MVTec-AD style industrial product images.

INPUT

288×288×3

Raw RGB, 0–255. EfficientNet rescales internally.

AUGMENTATION

Data Aug. (train only)

Flips, rotations — inactive at inference

BACKBONE

EfficientNetB0

ImageNet pretrained, fine-tuned top layers

POOLING

Global Avg Pool

Reduces feature maps to a vector

HEAD

Dense → Dropout

Task-specific classifier layers

OUTPUT

Softmax(2)

[P(defective), P(good)]

Decision threshold

If P(good) ≥ 0.58 → PASS. The threshold was tuned on the validation set to maximize balanced accuracy. On the held-out test set it gives defective recall of 93.8% and good recall of 96.1%.

Uncertain zone

When P(good) ∈ [0.48, 0.68] the model is near its decision boundary. The API returns status "uncertain" — flag for human review.

No pixel normalization

Raw 0–255 values are fed directly. The EfficientNetB0 head has an internal rescaling layer trained alongside the classifier.
